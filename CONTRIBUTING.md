# Contributing to Gemini AI Custom Skills Collection

Terima kasih telah tertarik untuk berkontribusi pada repositori ini!

## Cara Menambahkan Skill Baru

1. Buat direktori baru di dalam folder `skills/` dengan nama yang deskriptif (misal: `skills/my-new-skill`).
2. Buat file `SKILL.md` di dalam direktori tersebut dengan format YAML frontmatter yang sesuai:
   ```yaml
   ---
   name: my-new-skill
   description: Deskripsi rinci kapan dan bagaimana skill ini digunakan.
   ---
   # Judul Skill
   ...
   ```
3. Uji coba skill pada AI Agent untuk memastikan kejelasan dan efektivitas instruksi.
4. Buat Pull Request (PR) dengan deskripsi perubahan yang jelas.
